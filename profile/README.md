# Octri

Octri turns an OpenAPI spec into a docs site, SDKs in ten languages, an MCP server for AI agents, and monitoring for SDKs once their users opt in.

- Website: https://octri.dev
- Docs: https://docs.octri.dev
- CLI: `npm i -g @octri/cli`
- MCP server: `@octri/mcp` on npm, listed in the official MCP Registry as `dev.octri/mcp`

SDK runtimes for TypeScript, Python, Go, Rust, Ruby, PHP, Dart, Swift, Java, and Kotlin.

Questions or bugs: hello@octri.dev.
